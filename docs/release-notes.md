# mitotoReader 0.2.0-alpha.3

Windows x64 功能测试版。本次重点升级 AI 文档助手、OCR 安装与多语言支持，以及 PDF 连续阅读体验。

## 下载与使用

- **安装版：`mitotoReader-0.2.0-alpha.3-Setup.exe`**。双击安装即可使用阅读器与内置轻量 OCR。
- **便携版：`mitotoReader-0.2.0-alpha.3-win32-x64.zip`**。完整解压后运行 `mitotoReader.exe`，不要只复制 EXE。
- **源码包与 `SHA256SUMS.txt`**：供查看源码和校验下载文件。

安装版阅读数据保存在 `%APPDATA%/mitotoreader/`；便携版使用程序旁的 `mitoto-data/`。书库引用原文件，请保留原始文档。

## AI 文档助手

- 实装忠实翻译、OCR 文本校正、结构整理三种任务，支持选中文字、当前页、整份文档，以及分别选择轻量 OCR 或 Docling / MinerU 结果。
- 内置独立任务提示词：保护术语、数字、单位、公式、引文、否定与证据强度；不补造缺失内容，不确定片段标记待核对。
- 高级设置支持术语表、补充要求与分段长度。按段落和句子组织上下文，逐段保存并支持续跑；取消可中止当前请求，迟到结果不会覆盖当前文档。
- 增加数字 / 公式 / 引文变化提示、输出截断检测，以及对部分暂时性服务错误的有限重试。
- 支持 DeepSeek、Gemini、OpenAI、Claude、Qwen、Kimi；需自行配置 API Key 和账户可用的模型。

## OCR 与安装修复

- 修复 `ensurepip` 失败后残缺环境被反复复用的问题。安装前检查 Python 标准库，修复独立虚拟环境与 pip；系统 Python 不可用时，Windows x64 自动下载校验过的独立 CPython，也可指定本地 Python 路径。
- 新增个人阅读、Nature / Science 类论文、IEEE / ACM 类论文、医学论文、书籍与扫描档案预设。高级设置可编辑输入类型、文档特征、版式和 AI 结果排版，并在当前文档保存自定义方案。期刊预设是阅读偏好，并非官方投稿模板。
- 内置轻量 OCR 新增韩语、德语、法语、西班牙语、俄语、意大利语和葡萄牙语模型，保留中 / 日 / 英支持。

## 阅读与界面

- PDF 支持单页与连续纵向滚动切换；连续模式只绘制附近页面，页码跟随滚动，并支持目录、搜索、书签与批注。
- 增加鼠标滚轮翻页；单页模式在页面边缘翻页，EPUB 同样支持滚轮。保留 Ctrl + 滚轮缩放。
- 改善翻页时的文本显示、页码输入保护、状态文案、提示淡出和工作台排版。

## 验证与限制

- 本地通过 16 项 Node 用例及 PDF / EPUB / OCR / 书库 / 工作台集成测试；12 种 OCR 语言模式通过清晰合成样本验证，不能据此推断真实扫描件准确率。
- 已实际验证独立 Python、ensurepip 和 MinerU 4.x 组件安装。首次模型解析仍可能需要较大的下载和磁盘空间，并受模型源网络与硬件条件影响。
- 发布流程验证打包后程序、12 种 OCR 语言模式及安装后的程序，生成并核对发行文件 SHA-256。
- AI 协议和工作流使用模拟回复测试，未以付费模型评估真实翻译质量；结果仍需人工核对。OCR 校正只处理提取文字，不具备原图视觉核验能力。使用 AI 会把所选文字、有限上下文及偏好发送给所选服务商，可能产生费用。
- Office / ODF 仍是文字阅读模式，不保留复杂版式和嵌入媒体。连续纵向阅读本轮用于 PDF。
