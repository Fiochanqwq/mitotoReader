# mitotoReader 0.2.0-alpha.1

Windows x64 离线阅读器。本版加入全文搜索、书签、全屏与页面适配、持久书库，以及框选 / 批量 OCR。

## 下载与使用

- **推荐：`mitotoReader-0.2.0-alpha.1-Setup.exe`**。双击安装，支持中文安装向导、安装目录选择、桌面和开始菜单快捷方式。无需另装 Node.js 或 OCR 模型。
- **便携版：`mitotoReader-0.2.0-alpha.1-win32-x64.zip`**。完整解压后运行 `mitotoReader.exe`，不要只复制 EXE。
- `source.zip` 为源码；`SHA256SUMS.txt` 提供下载文件校验值。

安装版将阅读数据保存在 `%APPDATA%/mitotoreader/`，卸载保留该目录。便携版仍使用程序旁的 `mitoto-data/`。从便携版迁移到安装版时，先关闭阅读器，再把 `mitoto-data` 中的 `reader.json` 和可选的 `ocr-cache` 复制到上述用户数据目录。书库引用原文件，请保留原始图书。

## 更新

- PDF / EPUB 全文搜索、结果跳转与单书书签；自动整页 / 宽度适配、全屏、窄窗口布局和快捷键帮助。
- 多文件书库导入、内容去重、封面和元数据、搜索筛选排序、阅读进度、失效文件重新定位。
- OCR 框选、旋转、对比度增强、最多 100 页的顺序队列、结果缓存、识别引擎复用与闲置释放。
- 控制 PDF 与 OCR 图像内存，合并配置写入；修复新版 PDF.js 关闭文档和切换时的资源销毁问题。

快捷键：`Ctrl+O` 打开、`Ctrl+F` 搜索、`Ctrl+D` 书签、`F11` 全屏、`Ctrl+0` 整页适配、`PageUp/PageDown` 翻页。

## 验证与限制

发布流程验证便携版阅读 / OCR / 书库 / 长篇 EPUB 回归、五种 OCR 语言模式，以及安装后的程序。识别准确率仍受扫描质量和版式影响；日文竖排合成样本仍有错字。尚不支持自动纠偏、批注、密码 PDF 或云同步。

此安装包未购买代码签名证书；Windows 可能显示未知发布者提示。请从本仓库 Releases 下载并核对校验值。
