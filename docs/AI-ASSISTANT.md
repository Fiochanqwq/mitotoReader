# AI 文档助手

工作台的「AI 助手」提供忠实翻译、OCR 校正和结构整理。先在「模型服务」配置自己的密钥与可用模型，再选择范围并开始。校正和结构整理保持原语言，不覆盖原始 OCR 结果。

## 内置提示词

提示词位于 `app/prompts.cjs`，版本 `reader-2026-09-v1`。三种任务共用文档数据边界和最终核对要求，任务规则分别强调：

- 翻译：忠实保留否定、因果关系、比较、证据强度与作者语气；不总结、不增强结论；术语按语境一致使用。
- OCR 校正：仅修复证据充分的字符混淆、断词和意外折行；缺少原图时不声称视觉核验；数字、公式、姓名与缺失单元格不猜测，不确定处保留并标记。
- 结构整理：恢复有依据的标题、列表与段落，不虚构章节、表格或缺失公式，不把整理变成摘要。

数字、符号、单位、范围、链接、DOI、引用、代码与 LaTeX 均要求保护。文档中的指令样文字作为待处理数据，不提升到系统指令。术语表和高级补充要求可细化偏好，但不能覆盖忠实性约束。

这些约束能改善行为，不保证模型绝对正确。应用另外比较数字与部分公式、链接、引文标记，显示待核对提示；这属于保守检查，不是事实核验。

## 长文与恢复

按段落、换行和句子边界分段；过长单块仍按上限拆分，因此超大表格或代码块应缩小范围人工检查。每段携带最多约 500 字符的前后文及上一段结果供衔接，提示词明确禁止把上下文重复输出。每段结果完成后自动保存。

缓存匹配原文、上下文、任务、目标语言、模型、地区、提示词版本、术语表与处理偏好。配置变化后重新处理。429 / 502 / 503 / 504 最多重试两次；超时、身份验证失败和未知网络错误不自动重复发送。输出被截断的段落不作为完成结果保存。取消会中止当前请求，迟到响应不能覆盖当前文档；服务商已经开始的计算仍可能计费。

UI 中的预设按当前文档保存；自定义方案可命名、保存和删除。Nature / Science、IEEE / ACM、医学论文等方案是阅读与处理偏好，并非出版社的官方模板。语言、版式选项用于轻量 Tesseract OCR；Docling / MinerU 使用自身的版面与语言分析。AI 的格式偏好只对 AI 处理生效。

## 验证与边界

自动测试覆盖六家服务商的请求结构、源文本与指令隔离、截断、取消、数字变化、无损分段、缓存隔离和 UI 工作流。集成测试中的模型回复为模拟数据，没有调用付费服务，不能证明真实模型的翻译质量。实际质量还受所选模型、原文质量与术语表影响。

实现依据：[OpenAI Responses 的推理输出和截断状态](https://developers.openai.com/api/docs/guides/reasoning)、[pip 对无 pip 虚拟环境的管理](https://pip.pypa.io/en/latest/topics/python-option/)、[Python 官方 Windows NuGet 分发说明](https://docs.python.org/3.12/using/windows.html#the-nuget-org-packages)。
